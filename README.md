# behavioral-data-analysis
A mixed-methods behavioral data pipeline using R and Python to analyze the cognitive and neurobiological impact of media metrics on human relationship expectations across a targeted experimental cohort.
# Mixed-Methods Behavioral Data Pipeline: Media Metrics vs. Relationship Ideals

## 📊 Project Overview
This repository contains the statistical scripts and data configuration workflows utilized during a mixed-methods empirical pilot study investigating human decision-making, neurobiological bonding triggers (specifically mesolimbic dopamine pathways and oxytocin modulation), and the direct influence of modern media metrics on relationship satisfaction. 

The project bridges the gap between immediate cognitive shifts measured through experimental manipulation and subjective lived experiences gathered via semi-structured interviews.

## 🛠️ Technical Stack
* **Languages:** R (Core Statistical Processing & Ordinal Comparisons), Python (Data Cleaning Pipeline)
* **Qualitative Framework:** Braun & Clarke Thematic Analysis
* **Psychometric Validation Scales Used:** Hendricks’ Relationship Satisfaction Scale (1988), Sprecher-Metts Romantic Ideals Scale (1999)

## 📈 Repository Contents & Architecture
* `/scripts/data_cleaning.py`: Custom Python automated cleaning protocols to format raw survey outputs into structured, analysis-ready CSV matrices.
* `/scripts/statistical_modeling.R`: R scripts executing descriptive statistics (measures of central tendency and dispersion calculations) across the 10-participant target cohort (5 experimental, 5 control).
* `/documentation/pilot_proposal.md`: Detailed project operational documentation outlining data protection, informed consent, right to withdraw protocols, and data triangulation frameworks.

## 🔑 Core Analytical Insights Developed
1. Structured pre- and post-exposure data models using descriptive statistics to systematically isolate shifting cognitive scores across baseline test groups.
2. Implemented qualitative thematic mapping to capture text data nuances, complementing statistical variance outputs to ensure comprehensive ecological validity.
